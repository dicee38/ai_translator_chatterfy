# Подключение Chatterfy Translator

Инструкция для покупателя — ~20 минут, один раз.

Расширение состоит из двух частей: расширение Chrome (отдаём вам) и ваш
собственный сервер-прокси с вашим ключом OpenAI (поднимаете сами за
несколько команд). Чужие переводы, чужой бюджет — не видите и не делите
ни с кем: каждая компания работает на своём сервере и своём ключе.

## Что нужно подготовить заранее

- **Аккаунт OpenAI** с пополненным балансом ([platform.openai.com](https://platform.openai.com)) — на нём считается расход за перевод и расшифровку голосовых.
- **Аккаунт Cloudflare** — бесплатный, без карты ([workers.dev](https://workers.dev)). На нём будет жить ваш личный сервер-прокси.
- **Node.js**, установленный на компьютере, с которого будете разворачивать сервер ([nodejs.org](https://nodejs.org), LTS-версия).
- **Браузер Chrome** — расширение делалось под него.

## 1. Поднимаем ваш сервер

Сервер — маленькая программа на Cloudflare Workers, которая держит ваш
ключ OpenAI и считает бюджет. Все команды — в терминале, из папки
`proxy/workers` внутри присланного проекта.

### 1.1 — зависимости и вход в Cloudflare

```sh
# установить зависимости
npm install

# откроет браузер для входа в ваш аккаунт Cloudflare
npx wrangler login
```

### 1.2 — своё хранилище для счётчика бюджета

Сервер использует Cloudflare KV, чтобы хранить сумму дневного расхода.
Нужно создать своё — чужое (из примера в проекте) использовать нельзя,
оно привязано к другому аккаунту.

```sh
npx wrangler kv namespace create BUDGET_KV
```

Команда напечатает примерно такой блок — скопируйте из него значение `id`:

```toml
[[kv_namespaces]]
binding = "BUDGET_KV"
id = "a1b2c3d4e5f6..."
```

Откройте файл `wrangler.toml` (в той же папке `proxy/workers`) и замените
им **оба** значения — `id` и `preview_id` — в блоке `[[kv_namespaces]]`.

> **Важно:** если пропустить этот шаг, деплой либо упадёт с ошибкой
> доступа, либо попытается использовать чужое хранилище. Шаг обязателен,
> не опциональный.

### 1.3 — секреты: ваш токен доступа и ваш ключ OpenAI

Сначала придумайте токен — любая длинная случайная строка, её
расширение будет предъявлять серверу. Получить такую можно одной
командой:

```sh
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"
```

Скопируйте получившуюся строку — она понадобится ещё раз на шаге 2.
Теперь передайте токен и ключ OpenAI серверу:

```sh
npx wrangler secret put EXTENSION_TOKEN
# вставит значение из предыдущего шага, когда попросит

npx wrangler secret put OPENAI_API_KEY
# вставит ваш ключ с platform.openai.com (начинается с sk-...)
```

### 1.4 — деплой

```sh
npx wrangler deploy
```

В выводе будет строка вида
`https://chatterfy-translator-proxy.ваш-поддомен.workers.dev` — это
адрес вашего сервера. **Сохраните его**, он понадобится на следующем шаге.

### 1.5 — проверка

Откройте в браузере `<ваш адрес>/health`. Должен появиться текст вида
`{"ok":true,...}` — сервер жив и готов.

## 2. Подключаем расширение к вашему серверу

### 2.1 — укажите свой сервер в манифесте

Откройте `extension/manifest.json` любым текстовым редактором. В
списке `host_permissions` замените строку с адресом сервера-примера на
ваш, полученный на шаге 1.4 (остальные строки — домены Chatterfy — не
трогайте):

```json
"host_permissions": [
  "https://v2.chatterfy.ai/*",
  "https://migration-api.chatterfy.ai/*",
  "http://localhost:8787/*",
  "https://chatterfy-translator-proxy.ваш-поддомен.workers.dev/*",
  "https://prod-chatterfy-v1-files.s3.eu-central-1.amazonaws.com/*",
  "https://prod-chatterfy-v1-files.s3-eu-central-1.amazonaws.com/*"
]
```

> **Важно:** без этой правки расширение не сможет достучаться до
> вашего сервера — браузер заблокирует запрос.

### 2.2 — установите расширение в Chrome

1. Откройте `chrome://extensions`
2. Включите переключатель «Режим разработчика» (правый верхний угол)
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension/`

### 2.3 — впишите адрес сервера и токен

Нажмите на иконку расширения в панели Chrome. В полях «Адрес прокси» и
«Токен» вставьте значения с шага 1 (адрес из 1.4, токен из 1.3) и
нажмите «Сохранить». Под полями появится индикатор дневного бюджета.

## 3. Проверка

- **Перевод по выделению:** на `v2.chatterfy.ai` выделите мышью текст
  входящего сообщения — появится всплывающая плашка с переводом.
- **Перевод своего черновика:** наберите ответ в поле ввода, нажмите
  кнопку в углу поля — текст заменится переводом на диалект собеседника.
- **Голосовые:** рядом с входящим голосовым сообщением появится кнопка
  «Перевести» — расшифровка и перевод придут в несколько секунд.

Если всё это сработало — установка завершена, дальше можно давать
доступ сотрудникам.

## Если сотрудников несколько

По умолчанию один токен действует на всех. Чтобы выдать **каждому
сотруднику свой** (и видеть расход по каждому отдельно):

```sh
npx wrangler secret put EXTENSION_TOKENS
```

Когда попросит значение — вставьте JSON вида:

```json
{"токен-ивана": "Иван", "токен-марии": "Мария"}
```

Токены — любые случайные строки (см. команду генерации в шаге 1.3,
выполнить несколько раз). Передеплойте сервер (`npx wrangler deploy`),
затем каждый сотрудник вписывает **свой личный** токен в попап
расширения — адрес сервера у всех общий.

## Лимиты и бюджет

Защита от случайного перерасхода уже встроена, настраивается теми же
секретами/переменными сервера.

| Переменная | Что делает |
|---|---|
| `DAILY_BUDGET_USD` | общий дневной потолок компании в долларах (уже задан, можно изменить в `wrangler.toml`) |
| `MONTHLY_BUDGET_USD` | месячный потолок компании — опционально |
| `EMPLOYEE_DAILY_BUDGET_USD` | личный дневной потолок на сотрудника — опционально, требует `EXTENSION_TOKENS` |
| `RATE_LIMIT_PER_MINUTE` | лимит запросов в минуту с одного токена, на случай зависания/бага (по умолчанию 20) |
| `ADMIN_TOKEN` | свой отдельный секрет для просмотра расхода (см. ниже) |

Переменные без приставки «секрет» — в `wrangler.toml`, блок `[vars]`.
Остальные — через `npx wrangler secret put ИМЯ`, так же как в шаге 1.3.

### Как посмотреть расход по сотрудникам

После того как задан `ADMIN_TOKEN`, расход за сегодня и за месяц — по
компании в целом и по каждому сотруднику отдельно — доступен по
адресу:

```
GET <адрес сервера>/admin/usage
Заголовок: X-Admin-Token: <ваш ADMIN_TOKEN>
```

Удобно проверить через curl или Postman; текста переписки там нет —
только суммы.

> **Рекомендация:** дополнительно задайте жёсткий лимит расходов прямо
> в дашборде OpenAI (Billing → Limits). Это единственная защита,
> которая не зависит от правильности счётчика на вашем сервере.

## Частые проблемы

| Симптом | Причина / что делать |
|---|---|
| Плашка перевода не появляется | проверьте, что вы на `v2.chatterfy.ai`, и перезагрузите расширение (кнопка ↻ на карточке в `chrome://extensions`) после правки манифеста |
| В попапе «Прокси недоступен» | откройте `<адрес>/health` в браузере напрямую — если не отвечает, сервер не задеплоен или адрес указан с опечаткой |
| Ошибка 401 / «неверный токен» | токен в попапе не совпадает с тем, что задан в `EXTENSION_TOKEN`/`EXTENSION_TOKENS` на сервере |
| Ошибка 429 / «бюджет исчерпан» | дневной лимит `DAILY_BUDGET_USD` исчерпан — поднимите значение в `wrangler.toml` и передеплойте, либо дождитесь сброса в полночь по UTC |
| Ошибка сети / CORS в консоли | забыт шаг 2.1 — адрес сервера не добавлен в `host_permissions` манифеста |
| Голосовое не предлагает перевод | по задумке работает только для входящих голосовых, не для своих |

---

Инструкция описывает вариант сервера на Cloudflare Workers (бесплатный
тариф, рекомендуется). Есть и вариант для собственного VPS — те же
переменные, но через обычный файл `.env` вместо `wrangler` (папка
`proxy/` вместо `proxy/workers/`).
